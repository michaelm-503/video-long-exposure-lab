# Sample Data

Place short local demo videos in this directory when testing the app or preparing
a hosted portfolio demo.

Supported local sample formats:

- `.mp4`
- `.mov`
- `.m4v`

Videos are intentionally not committed to the repository. This keeps the public
repo small and avoids redistributing media that may have separate license terms.

The app's Demo Gallery can use:

- hosted clips from the project's demo media release:
  https://github.com/michaelm-503/video-long-exposure-lab/releases/tag/demo-media-v1
- local files placed in this directory
- direct remote video URLs that end in `.mp4`, `.mov`, or `.m4v`

If you want to test private or larger clips locally, place them here and select
them from the Demo Gallery.
